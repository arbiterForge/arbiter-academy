Arbiter Academy Preview 0.1

Practice codeArbiter in a real Git repository through eight available labs, paced at 20–35 minutes each.

Before you begin

You need Git, a GitHub account, codeArbiter, and the reviewed arbiter-academy package installed outside the learner checkout.

Start safely

  1. Fork the Academy. Create your own GitHub fork of arbiterForge/arbiter-academy.
  2. Clone your fork. git clone https://github.com/<your-account>/arbiter-academy.git

    Work only in that clone. Your origin and every push destination must be your fork; the canonical Academy repository is reference-only.

  3. Prepare a lab. From the installed Academy CLI, select the learner checkout explicitly:

    arbiter-academy --repository <learner-repository> prepare <lab-id>

  4. Work and check. Complete the lesson with codeArbiter and Git, then use the installed verifier:

    arbiter-academy --repository <learner-repository> check <lab-id>

  5. Reset only for a documented retry. Preserve the failed attempt, return it to a clean state, then run:

    arbiter-academy --repository <learner-repository> reset <lab-id>

The installed verifier is the trust anchor. The selected learner checkout, including its Git and artifact data, is untrusted input.

Preview limits

Preview 0.1 is static, local training. P05–P07 are status-only, P08 and the Power User labs are not included, and this Preview provides no hosted execution, hosted verification, or signed credential.
